**Algoritmos 112 a 120 em Kotlin**

Este repositório contém os algoritmos de 112 a 120, originalmente escritos em Portugol e convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e aprofundar o uso de estruturas condicionais aninhadas, operadores relacionais e lógicos, além de manipulação de funções matemáticas e lógica de ordenação sequencial.

**Algoritmos desenvolvidos**

Algoritmo 112: Entra com dois números e imprime o menor número (supondo números diferentes).

Algoritmo 113: Entra com dois números e imprime-os em ordem crescente (supondo números diferentes).

Algoritmo 114: Entra com dois números e imprime-os em ordem decrescente (supondo números diferentes).

Algoritmo 115: Entra com dois números e imprime o quadrado do menor número e a raiz quadrada do maior número, se for possível.

Algoritmo 116: Entra com três números e imprime o maior número utilizando diferentes abordagens condicionais (supondo números diferentes).

Algoritmo 117: Entra com três números e armazena o maior número na variável de nome maior (supondo números diferentes).

Algoritmo 118: Entra com três números e imprime-os em ordem crescente utilizando variáveis auxiliares para troca (supondo números diferentes).

Algoritmo 119: Entra com três números e imprime-os em ordem decrescente.

Algoritmo 120: Entra com três números e armazena-os em três variáveis com os nomes maior, intermediário e menor (supondo números diferentes).

**Comentários sobre os exercícios**

Neste bloco, consegui consolidar o uso de estruturas condicionais avançadas, encadeamentos múltiplos e a manipulação de variáveis auxiliares (`aux`) para realizar trocas de valores (`swap`), fundamentais para algoritmos de ordenação.

Também aprofundei o uso de funções matemáticas como `sqrt` para o cálculo de raízes quadradas e a tradução limpa e idiomática de lógicas de decisão do Portugol para o Kotlin.

Os exercícios ajudaram a compreender melhor como estruturar comparações complexas entre múltiplos valores e a manter o código limpo e organizado.

**Ferramentas utilizadas**

- IntelliJ IDEA

**Organização**

Os arquivos estão organizados individualmente, de Algoritmo112.kt até Algoritmo120.kt, dentro da pasta src/main/kotlin.

Cada arquivo contém o enunciado, o código original em Portugol e sua conversão para Kotlin.
